# Standing Rule: Automatic GitHub Push

Whenever any modification, fix, or feature update is made to the codebase or website:
1. Validate the changes with `npm run build` to ensure zero compilation or syntax errors.
2. Immediately stage the modified files (`git add .`).
3. Commit with a clear, descriptive message (`git commit -m "..."`).
4. Push directly to GitHub (`git push origin main`).
